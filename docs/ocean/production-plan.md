# SWIPE EARTH: OCEAN 制作計画

## 目的

OCEANを「1体ずつ切り替える図鑑」から、同じ深度帯に複数の生物が存在する**群生型・探索型の海中体験**へ刷新する。

通常時は海そのものを眺め、生物をタップしたときだけ名前・深度・解説が現れる。スマートフォン縦画面を最優先する。

## 品質原則

1. CSSアートを完成素材として使わない。
2. 生物・UMA・背景・主要FXは独立した画像素材で制作する。
3. 小さく表示しても種類を判別できるシルエットを優先する。
4. 科学情報と演出上のフィクションを明確に分離する。
5. 画像破損、全透明画像、参照切れを自動検査する。
6. 50体を一括投入せず、1ゾーンの完成度を確認してから量産する。
7. iPhone Safariで成立しない表現は採用しない。

## フェーズ

### Phase 1: 基準確定

- [x] 群生型への方向転換
- [x] 役割と作業Issueの分割
- [x] 制作計画のリポジトリ登録
- [ ] SUNLIT / MIDNIGHT / HADAL の完成モックを確定
- [ ] アートディレクションを確定
- [ ] 素材規格と検査ツールを確定
- [ ] 生物50種の調査と分類を確定

### Phase 2: 垂直試作

対象は **MIDNIGHT ZONE** とする。

- 6〜10種類を同一画面内へ配置
- 小型群生、中型、主役大型、遠景シルエットを混在
- 生物タップで詳細カードを表示
- 大型生物はゆっくり画面を横切る
- UMAは常時目立たせず、発見型の演出にする
- 深度、ゾーン、進行方向のみ常設表示

### Phase 3: 実機評価

- iPhone主要幅で確認
- Safariのスクロール・タップ・画像読み込みを確認
- テキストと生物の衝突を確認
- 背景・生物・FXを同時表示した性能を確認
- reduced-motionを確認

### Phase 4: 全体展開

- SUNLIT / TWILIGHT / ABYSSAL / HADALへ展開
- 優先20体を本番投入
- 残り30体を制作・調査・投入
- 図鑑、発見履歴、レア遭遇を追加

## 作業順序

1. 完成画面の基準を固定する
2. 生物データと素材規格を固定する
3. 素材検査を自動化する
4. 優先生物と背景を制作する
5. MIDNIGHT ZONEを完成させる
6. 実機QAを通す
7. 合格後に他ゾーンへ横展開する

## リリース判定

以下をすべて満たした場合のみ次フェーズへ進む。

- 画像の404・破損・全透明が0件
- 主要生物がスマホ上で識別可能
- 群生しても主役と遠景の階層が分かる
- タップ対象が小さすぎない
- 主要操作を片手で行える
- 科学情報に出典または調査済みフラグがある
- 60秒眺めても単調に見えない動きがある
- 動きを減らす設定でも情報が失われない
