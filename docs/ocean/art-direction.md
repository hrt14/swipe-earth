# SWIPE EARTH: OCEAN アートディレクション

## 体験の核

画面は図鑑カードではなく、ユーザーが覗き込む**海中の窓**として設計する。

- 縦スクロール：深く潜る
- 画面内の生物：同じ深度帯で共存する
- タップ：生物を発見して知る
- 通常時：UIより海を主役にする

## 画面密度

スマートフォン縦画面1枚につき、目安として以下を同時表示する。

- 主役大型生物：0〜1体
- 中型生物：2〜4体
- 小型生物：4〜12体
- 群れ・反復個体：1〜3グループ
- 遠景シルエット：1〜3体
- UMA・未知の影：0〜1体

すべてを均等に並べず、空白を残す。視線が「主役 → 中型 → 小型 → 遠景」へ流れる構図にする。

## 奥行きレイヤー

### 背景

- サイズ：基準の35〜55%
- 不透明度：25〜55%
- 彩度・コントラストを抑える
- タップ対象にしない場合がある
- ゆっくりした移動または静止

### 中景

- サイズ：基準の65〜100%
- 不透明度：75〜100%
- 主な発見対象
- タップ可能領域は画像より広く取る

### 前景

- サイズ：基準の110〜170%
- 画面端から一部が切れてもよい
- 常時置かず、通過演出に使う
- テキストUIを覆わない

## 生物の見せ方

### 小型群生

- 同一画像の単純なコピペに見せない
- 大きさ、向き、速度、開始位置を変える
- 3〜7体程度をひとまとまりとして扱う
- 画面中央を塞がず、斜めの流れを作る

### 中型生物

- 同一画面で2〜4種類
- 互いに重ならない主要シルエットを選ぶ
- タップ時だけ細いリングまたは小さなラベルを表示

### 大型生物

- 1ゾーンに主役を1体まで
- 全身を常に見せる必要はない
- 画面横断、遠景通過、部分的な登場を使い分ける
- スクロール位置に応じて存在感を変える

### UMA・伝承

- 通常生物と同じ明るさ・輪郭で置かない
- 霧、暗部、画面端、遠景を利用する
- 初回は名称を隠してもよい
- 科学的に確認された生物とUI上で区別する

## ゾーン別の視覚ルール

### SUNLIT

- 明るい青緑
- 水面の光条と反射
- 群れの動きが多い
- 小型魚と大型回遊生物を組み合わせる

### TWILIGHT

- 青から濃紺への移行
- 上方からの光が残る
- 生物間の空白が増える
- 反射、銀色、透明感を強調する

### MIDNIGHT

- 深い紺と黒
- 生物発光を主要な光源にする
- 6〜10種類を配置する試作対象
- 赤、紫、青緑のアクセントを限定的に使う

### ABYSSAL

- 視界が狭く、海底の存在を感じさせる
- 浮遊生物と底生生物を分ける
- 動きは遅く、粒子は細かい

### HADAL

- ほぼ黒に近い背景
- 生物数を減らし、未知の空間を大きく取る
- 突然の巨大影や微弱な光を使う
- UMAを出しすぎない

## UIルール

### 常設UI

- SWIPE EARTH / OCEAN
- 現在深度
- ゾーン名
- 縦方向の進行が分かる最小限の深度表示

### タップ時UI

- 英語名 / 日本語名
- 代表深度または観察範囲
- 1〜2文の短い解説
- 実在生物 / 伝承 / 未確認の分類
- 閉じる操作

詳細カードは画面下部に置き、選択中の生物を完全に隠さない。

## モーション

- 小型群生：緩やかな横移動 + 個体差
- クラゲ・タコ類：上下の浮遊
- 大型生物：長い周期で画面横断
- 粒子：背景と異なる速度で奥行きを作る
- タップ反応：短いリングまたは発光

`prefers-reduced-motion` では移動量を大幅に減らし、フェード中心にする。

## 禁止事項

- 生物を均等なグリッドに並べる
- 全生物に常時ラベルを付ける
- 画面中央へ情報カードを常設する
- CSSだけで生物を描く
- 同じ浮遊アニメーションを全個体へ適用する
- UMAを通常生物より頻繁に見せる
- スマホで識別不能なほど小さくする
